# 🐻ㅣGOMS란?
광주소프트웨어마이스터고등학교의 **Team.GOMS**가 개발한 앱 서비스는 월요일과 수요일에 시행되는 외출제를 **효율적**으로 관리합니다.  
이 프로젝트는 복잡했던 외출 절차를 **간소화**하고, 학생회의 기존 **수기 관리 방식**을 디지털화하여 더욱 편리하고 체계적인 시스템을 구축했습니다.
